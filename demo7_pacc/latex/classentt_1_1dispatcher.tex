\doxysubsection{详细描述}
Basic dispatcher implementation. 

A dispatcher can be used either to trigger an immediate event or to enqueue events to be published all together once per tick.~\newline
 Listeners are provided in the form of member functions. For each event of type {\ttfamily Event}, listeners are such that they can be invoked with an argument of type {\ttfamily const Event \&}, no matter what the return type is.

The dispatcher creates instances of the {\ttfamily sigh} class internally. Refer to the documentation of the latter for more details.
