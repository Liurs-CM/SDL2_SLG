## 土/水/火/风本源元素论
- 土: 空间 - 边界
- 水: 趋势 - 可塑性
- 风: 交互 - 信息传递
- 火: 辐射 - 内在动力
- 灵魂: 元素之间的相互作用方式
感知：风（关联性）将外物信息传递进来。
感受：水（可塑性）接受这种传递，被其“塑形”而产生情绪与体感。
决断：火（主动性）决定是否行动。
记忆：土（承载性）将一切经历固化下来，形成“过去的我”。

 关键优势：
 1. 可读性：映射关系一目了然，文档化代码

 3. 可扩展性：新类型只需声明，无需编写解析逻辑
 4. 类型安全：编译期验证属性类型
 5. 可测试性：引擎和映射可独立测试
