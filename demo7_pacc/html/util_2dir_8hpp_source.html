46// Overloading increment and dereference operators to make Dir work as an
47// iterator in range-for loops. Dir is an iterator for itself. This isn't a
48// proper iterator. It's just the bare minimum to work with a range for loop.
49// Take the following snippet:
50//
51// for (const Dir dir : dir_range) {
52// ...
53// }
54//
55// This is de-sugared by the compiler into something like this:
56//
57// {
58// auto begin = dir_range.begin();
59// auto end = dir_range.end();

61// const Dir dir = *begin;
62// ...

64// }
