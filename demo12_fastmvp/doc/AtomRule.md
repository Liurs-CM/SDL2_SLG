## 目录
三个完全正交的原子系统: 物质流, 信号场, 驱力

## 物质流 Matter
### 定义
实体在世界中的存在、移动、转化、消亡
### 属性
struct MatterEntity {
    Vec2 position;          // 在哪
    MatterType type;        // 是什么（肉/木/石/水/人...）
    float quantity;         // 有多少
    float decay_rate;       // 衰变速率
};
### 规则
- R1: 扩散  —— 物质从高浓度向低浓度流动（水、气味、热量）
- R2: 转化  —— 物质A + 物质B → 物质C（火+木头=灰烬+热量; 人+浆果=饱腹的人+粪便）
- R3: 守恒  —— 转化前后总质量守恒（不凭空产生或消失）
- R4: 衰变  —— 所有有序物质趋向无序（食物腐烂、工具磨损、尸体分解）
### 衍生
#### 食物链
植物吸收土壤养分 → 食草动物吃植物 → 食肉动物吃食草动物 → 尸体分解回土壤
#### 季节系统
太阳热量是输入源，热量驱动转化速率变化
#### 生态平衡
捕食者增多 → 猎物减少 → 捕食者饿死 → 猎物恢复

## 信号场 Signal
信息在空间/个体间的传播、衰减、变异(不是消息系统, 而是物理场)
### 属性
struct Signal {
    Vec2 origin;            // 信号源
    SignalType type;        // 类型（视觉/声音/气味/符号/语言）
    float intensity;        // 强度
    float fidelity;         // 保真度（每次传递会失真）
};
### 规则
- R1: 发射  —— 物质事件产生信号（走路→脚印+声音; 生火→光+烟）
- R2: 衰减  —— 信号强度随距离/时间衰减（声音消散、脚印风化）
- R3: 变异  —— 信号经个体转述后保真度下降（口耳相传的信息失真）
### 衍生
#### 追踪机制
（猎物留下气味信号，猎手读取信号）
#### 战争迷雾
（信号衰减 = 信息不完整）
#### 谣言与误解
（信号变异 = 信息失真 → "赤石部落要攻击我们"可能是"赤石部落在举办庆典"的误传）
#### 语言与符号
（高保真信号需要发明编码方式 → 文字起源）

## 驱力 Drive
个体的内在需求向量与偏好
### 属性
struct DriveVector {
    // 一个多维向量，每个维度是一种内在驱力
    float hunger;       // 进食
    float safety;       // 安全
    float social;       // 归属
    float curiosity;    // 探索
    float dominance;    // 支配
    // ... 可配置维度数量
};
### 规则
- R1: 效用评估  —— 对每个可选行动，计算它对各驱力维度的预期满足度的加权和
- R2: 权重自适应 —— 最匮乏的驱力维度自动获得更高权重（类似马斯洛层次，但连续且动态）


# 方法论: 最少正交组件
## 方法论 1：公理独立性验证（Axiomatic Independence Test）
## 方法论 2：MECE + 降维投影（Consulting-style Decomposition）
来源： 麦肯锡 MECE 原则（Mutually Exclusive, Collectively Exhaustive）结合线性代数降维
步骤：
1. 列出所有你需要的游戏现象（狩猎、战争、贸易、宗教、疾病...）共M个
2. 为每个现象标注它需要哪些"底层能力"
3. 构建 现象×能力 矩阵
4. 对矩阵做PCA（主成分分析）或类似降维
5. 提取出的前K个主成分 = 你的最少正交系统数量

关键检验：
- ME（互斥）：任何两个系统不应共享核心规则 → 正交
- CE（穷尽）：所有M个现象都能被这K个系统的组合解释 → 充分
## 方法论 3：Kolmogorov 复杂度 / 最小描述长度（MDL）
来源： 信息论（Kolmogorov Complexity, Rissanen's MDL Principle）
核心思想： 最优的系统分解，是使"描述所有规则所需的总信息量"最小的那种分解。
## 方法论 4：对抗性消融测试（Adversarial Ablation）
来源： 机器学习中的消融实验（Ablation Study）
步骤：
1. 构建完整可运行的最小原型（即使只是纸面模拟或极简代码）
2. 逐一关闭每个原子系统
3. 观察"趣味性"是否坍塌

判定标准：
- 关闭后趣味性缓慢下降 → 该系统是"锦上添花"，可以移除
- 关闭后趣味性立刻坍塌，且无法被其他系统补偿 → 该系统是"承重墙"，必须保留
- 关闭后反而更有趣 → 该系统是"噪声源"，应该移除

## 方法论 5：Wolfram 计算等价性检验
来源： Stephen Wolfram《A New Kind of Science》
核心思想： 如果一个系统的规则集能达到"图灵完备"级别的计算能力，那么它在理论上可以涌现出任意复杂度的行为。
检验方法：
- 你的规则组合是否能表达条件分支？（驱力系统的效用评估 = if-else）
- 你的规则组合是否能表达循环/迭代？（物质流的tick循环 + 信号衰减 = while loop）
- 你的规则组合是否能表达状态存储？（物质实体的position/type = memory）

三者都有 → 计算完备 → 理论上可以涌现出任意复杂度
