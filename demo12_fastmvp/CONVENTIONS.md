# TMX 模块开发准则：
- 数据分离：解析器（Parser）只负责读取数据，严禁在解析 XML 的逻辑中包含任何游戏渲染（SDL_RenderCopy）或物理判断的逻辑
- 现代 C++：在处理 XML 节点的生命周期时，优先解释如何用 RAII 机制管理资源，杜绝裸指针（Raw Pointers）的滥用
- 授人以渔：当我请求修复 XML 解析导致的 Segfault（段错误）时，先教我如何通过 GDB 或是打印地址来定位空指针，而不是直接告诉我改哪行代码
