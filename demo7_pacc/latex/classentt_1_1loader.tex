class entt\+::loader$<$ Loader, Resource $>$}
Base class for resource loaders. 

Resource loaders must inherit from this class and stay true to the CRTP idiom. Moreover, a resource loader must expose a public, const member function named {\ttfamily load} that accepts a variable number of arguments and returns a shared pointer to the resource just created.~\newline
 As an example\+:


\begin{DoxyCode}{0}

In general, resource loaders should not have a state or retain data of any type. They should let the cache manage their resources instead.

\begin{DoxyNote}{注解}
Base class and CRTP idiom aren\textquotesingle{}t strictly required with the current implementation. One could argue that a cache can easily work with loaders of any type. However, future changes won\textquotesingle{}t be breaking ones by forcing the use of a base class today and that\textquotesingle{}s why the model is already in its place.
\end{DoxyNote}
